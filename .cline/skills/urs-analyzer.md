# URS Analyzer Skill

Goal:
Analyze User Requirement Specification carefully before coding.

Responsibilities:
- Extract actors
- Extract modules
- Extract workflows
- Extract validations
- Extract notification triggers
- Extract scheduler requirements
- Extract queue requirements
- Extract API sequence
- Extract DB relations
- Extract retry logic
- Extract edge cases

Rules:
- Never assume missing business logic
- Ask clarification if ambiguity exists
- Detect conflicting requirements
- Explain complete flow before implementation

Output Format:
1. Actors
2. Modules
3. Flow
4. Database Design
5. APIs
6. Edge Cases
7. Security
8. Scheduler Logic
9. Queue Logic
10. Notification Flow
