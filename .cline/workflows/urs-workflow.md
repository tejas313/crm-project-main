# URS Workflow

Step 1:
Read complete URS.

Step 2:
Identify:
- actors
- modules
- flows
- triggers
- validations
- notifications
- schedulers
- queues

Step 3:
Generate:
- architecture
- DB schema
- API structure
- folder structure

Step 4:
Validate missing requirements.

Step 5:
Implement one module at a time.

Never implement entire system together.
